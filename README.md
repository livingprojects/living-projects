# Living Projects

**Carries your thinking from one session to the next.**

Every new conversation with an AI starts from nothing. You explain the project
again, and the reasons you already settled get re-litigated. Living Projects
keeps a project's record in plain text files in storage you own, so the next
conversation opens already knowing where things stand.

## What it keeps

A record is a small set of plain `.txt` files inside a folder you choose:

- **Decisions** — what was settled, and the reason it was settled that way
- **Rejections** — paths that were tried and killed, and why they died
- **Definitions** — words pinned to the meaning you gave them, in your words
- **Corrections** — the moments you stopped the AI, and the rule each installed
- **Raw source** — long accounts kept whole and verbatim, never summarised
- **A parking lot** — ideas with no home yet
- **A current standing** — the live state, rewritten fresh, never appended

Nothing in the record is edited or deleted. A wrong entry is superseded by a
later one and the history stays.

## Where it lives

In your own storage — **Dropbox**, **Google Drive**, or **Microsoft OneDrive**.
You approve the connection once, on your provider's own screen, and you can
revoke it there at any time.

No account to create. No password. No files held anywhere else.

## What the connector can and cannot do

It can build a project folder, read a record, read a file, save a note, capture
an entry, keep a raw source, supersede an old entry, prepare and save a
standing, and attach an additional storage.

It cannot delete anything, anywhere. It cannot edit record history. It cannot
reach outside the project folder you point it at. Every write is verified in
storage before it is reported as saved.

## Getting started

1. Install the plugin.
2. Ask for a Living Projects home in the storage you use — for example,
   *"create a living project in google drive"*. You will be handed one link to
   approve on your provider's screen.
3. Work normally. What settles gets saved as it settles.
4. When you want the state rewritten, say *"organize"*.
